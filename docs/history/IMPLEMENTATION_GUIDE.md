## 🐛 حل المشاكل المحتملة:

### المشكلة 1: "Access denied for user"
**الحل:**
```bash
# استخدم كلمة المرور الصحيحة
mysql -u root -p
# ثم أدخل كلمة المرور عند الطلب
```

### المشكلة 2: "Database does not exist"
**الحل:**
```bash
# تأكد من اسم قاعدة البيانات
mysql -u root -p -e "SHOW DATABASES;"
# استخدم الاسم الصحيح
```

### المشكلة 3: "Duplicate entry"
**الحل:**
- البيانات موجودة بالفعل - هذا جيد!
- يمكنك حذف البيانات القديمة أولاً:
```sql
DELETE FROM important_links WHERE id > 0;
```

### المشكلة 4: scraping من وزارة الصحة يعطي 0
**الحل:**
- الموقع قد يكون بطيء أو معطل مؤقتاً
- جرب لاحقاً
- استخدم البيانات الأولية اليدوية (كافية)
