## 📋 المصادر الموجودة في قاعدة البيانات:

### 1. ✅ دليل الحكومة اللبنانية - TRA

**معلومات المصدر:**
- **النوع:** Scraping (استخراج من HTML)
- **طريقة الجلب:** html_scraper
- **الرابط:** https://www.tra.gov.lb/useful-links-governmental-institutions
- **الفئة:** وزارات (category_id: 1)
- **التكرار:** شهري
- **الحالة:** نشط ✅

**التحليل:**
- ✅ الرابط صحيح وموجود
- ⚠️ **المشكلة المحتملة:** يحتاج إلى scraping selectors محددة
- ⚠️ بنية الصفحة قد تتغير بمرور الوقت

**الحل:**
- تحديد CSS/XPath selectors الصحيحة في حقل `scraping_selector`
- اختبار الـ selectors بشكل دوري

**مثال على Scraping Selector:**
```json
{
    "item_selector": "//table//tr[position()>1]",
    "fields": {
        "name_ar": ".//td[1]",
        "website": ".//td[2]//a/@href",
        "description_ar": ".//td[3]"
    }
}
```

**الإجراء المطلوب:**
1. زيارة الرابط وفحص بنية HTML
2. تحديث حقل `scraping_selector` في قاعدة البيانات
3. اختبار الجلب من صفحة الاختبار

### 2. ⚠️ مستشفيات حكومية - Open Data Lebanon

**معلومات المصدر:**
- **النوع:** API
- **طريقة الجلب:** file_import
- **صيغة الملف:** XLSX (Excel)
- **الرابط:** https://www.opendatalebanon.org/job/list-of-public-hospitals-in-lebanon/
- **الفئة:** مستشفيات حكومية (category_id: 2)
- **التكرار:** شهري
- **الحالة:** نشط ✅

**التحليل:**
- ⚠️ **مشكلة حرجة:** الرابط يشير إلى صفحة ويب وليس ملف Excel مباشر!
- ❌ لا يوجد رابط مباشر لتحميل ملف XLSX
- ⚠️ يحتاج إلى مكتبة PhpSpreadsheet لقراءة Excel

**الحل:**
1. تحديث الرابط ليشير لملف Excel مباشر
2. أو تغيير طريقة الجلب إلى scraping من صفحة الويب
3. أو تحميل الملف يدوياً ورفعه على السيرفر

**الإجراء المطلوب:**
1. زيارة الموقع والبحث عن رابط التحميل المباشر للـ Excel
2. تحديث `file_url` في قاعدة البيانات
3. التأكد من تثبيت مكتبة PhpSpreadsheet:
   ```bash
   composer require phpoffice/phpspreadsheet
   ```

### 3. ⚠️ مستشفيات - وزارة الصحة

**معلومات المصدر:**
- **النوع:** Scraping
- **طريقة الجلب:** html_scraper
- **الرابط:** https://www.moph.gov.lb/en/HealthFacilities/index/3/188/8?facility_type=1
- **الفئة:** مستشفيات حكومية (category_id: 2)
- **التكرار:** شهري
- **الحالة:** نشط ✅ (لكن auto_import = 0 ❌)

**التحليل:**
- ⚠️ **المشكلة:** `auto_import` معطل (0) - لن يتم الجلب تلقائياً
- ⚠️ يحتاج إلى scraping selectors محددة
- ⚠️ الصفحة باللغة الإنجليزية، قد تحتاج للعربية

**الحل:**
- تفعيل `auto_import = 1` إذا أردت جلب تلقائي
- تحديد scraping selectors الصحيحة

**مثال على Scraping Selector:**
```json
{
    "item_selector": "//div[@class='facility-item'] | //table//tr",
    "fields": {
        "name_ar": ".//h3 | .//td[1]",
        "phone": ".//span[@class='phone'] | .//td[2]",
        "address_ar": ".//span[@class='address'] | .//td[3]"
    }
}
```

**الإجراء المطلوب:**
1. فحص بنية صفحة وزارة الصحة
2. تحديد selectors المناسبة
3. تفعيل auto_import إذا لزم الأمر

## 🚨 المشاكل الرئيسية:

### 1. **عدم وجود scraping selectors محددة**
- المصادر التي تستخدم scraping تحتاج إلى تحديد دقيق لعناصر HTML
- بدون selectors، لن يتمكن النظام من استخراج البيانات

### 2. **روابط غير مباشرة أو مفقودة**
- بعض المصادر تشير لصفحات ويب عادية وليس APIs
- مصدر السفارات ليس له رابط على الإطلاق

### 3. **تنسيقات ملفات معقدة (PDF, Excel)**
- PDF صعب القراءة برمجياً
- Excel يحتاج مكتبة PhpSpreadsheet
