## كيفية الاستخدام

### الخطوة 1: تنفيذ SQL
```bash
mysql -u root -p tekrit_municipality < sql/add_ai_settings.sql
```

### الخطوة 2: تفعيل الذكاء الاصطناعي
1. دخول: `http://localhost:8080/tekrit_municipality/modules/system_settings.php`
2. انتقال لتبويب "الذكاء الاصطناعي"
3. اختيار المزود وإدخال API Key
4. تفعيل النظام
5. حفظ الإعدادات

### الخطوة 3: استخدام الميزات
#### إنشاء ميزانية:
1. دخول: `modules/budgets.php`
2. الضغط على زر "إنشاء بالذكاء الاصطناعي"
3. اختيار نوع الميزانية
4. الإجابة على الأسئلة
5. مراجعة الميزانية وحفظها

#### استخدام AI في صفحات أخرى:
```html
<script src="../js/ai_helper.js"></script>
<script>
// إضافة زر AI لحقل نصي
aiHelper.addAIButtonToField('description_field_id');
</script>
```
