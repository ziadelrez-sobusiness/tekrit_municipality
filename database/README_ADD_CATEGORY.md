## 📊 ماذا سيحدث؟

السكربت سيقوم بـ:

1. ✅ **إضافة حقل `category`** إلى جدول `permissions`
2. ✅ **إضافة حقل `updated_at`** إذا لم يكن موجوداً
3. ✅ **إضافة index** على حقل `category`
4. ⚠️ **حذف البيانات القديمة** من جدول `permissions` و `user_permissions`
5. ✅ **إدخال 115+ صلاحية جديدة** مقسمة على 9 فئات

## ✅ التحقق من النجاح

بعد تنفيذ السكربت، قم بتشغيل الاستعلامات التالية للتحقق:

### 1. التحقق من عدد الصلاحيات

```sql
SELECT COUNT(*) as total FROM permissions;
```

**النتيجة المتوقعة:** 115 أو أكثر

### 2. عرض الصلاحيات حسب الفئة

```sql
SELECT
    category as الفئة,
    COUNT(*) as عدد_الصلاحيات
FROM permissions
WHERE category IS NOT NULL
GROUP BY category
ORDER BY
    CASE category
        WHEN 'general_admin' THEN 1
        WHEN 'finance' THEN 2
        WHEN 'projects' THEN 3
        WHEN 'citizens' THEN 4
        WHEN 'services' THEN 5
        WHEN 'maps' THEN 6
        WHEN 'website' THEN 7
        WHEN 'reports' THEN 8
        WHEN 'settings' THEN 9
        ELSE 10
    END;
```

**النتيجة المتوقعة:**

```
+------------------+-------------------+
| الفئة            | عدد_الصلاحيات     |
+------------------+-------------------+
| general_admin    |                13 |
| finance          |                31 |
| projects         |                12 |
| citizens         |                18 |
| services         |                15 |
| maps             |                 6 |
| website          |                 8 |
| reports          |                 9 |
| settings         |                 3 |
+------------------+-------------------+
```

### 3. عرض بعض الصلاحيات الجديدة

```sql
SELECT
    permission_name,
    display_name,
    category,
    icon
FROM permissions
LIMIT 10;
```

## ⚠️ تحذيرات مهمة

### 🔴 انتبه!

1. **حذف البيانات**: السكربت يحذف جميع الصلاحيات القديمة من `permissions` و `user_permissions`
2. **فقدان الصلاحيات**: جميع المستخدمين سيفقدون صلاحياتهم ويجب إعادة ضبطها
3. **النسخ الاحتياطي**: **ضروري جداً** قبل التطبيق
4. **بيئة التطوير أولاً**: اختبر السكربت في بيئة تجريبية قبل الإنتاج

### 💡 نصائح

- قم بالتطبيق خارج ساعات العمل
- احتفظ بالنسخة الاحتياطية لمدة أسبوع على الأقل
- استخدم القوالب الجاهزة لتسريع إعادة ضبط الصلاحيات
- وثّق صلاحيات كل مستخدم قبل التطبيق
